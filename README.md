# wish-site demo

Live demo of [**wish-site**](https://github.com/ashishbhoure/wish-site) — cute, animated celebration websites for birthdays, anniversaries and more.

👉 **https://ashishbhoure.github.io/wish-site-demo/**

Try other looks by changing the URL:

- [`?theme=mint&character=bunny`](https://ashishbhoure.github.io/wish-site-demo/?theme=mint&character=bunny)
- [`?theme=sunshine&character=bear&number=30`](https://ashishbhoure.github.io/wish-site-demo/?theme=sunshine&character=bear&number=30)
- [`?theme=peach`](https://ashishbhoure.github.io/wish-site-demo/?theme=peach)
- [`?theme=rose&character=none`](https://ashishbhoure.github.io/wish-site-demo/?theme=rose&character=none)

Themes: `lavender rose mint sky peach sunshine berry` · Characters: `cat bunny bear none`.

This demo uses placeholder pictures. Make your own with real photos and messages by editing `config.js`
(or just ask Claude Code with the wish-site skill). MIT licensed.
